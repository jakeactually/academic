# academic

I made this system inspired by the application I had to use while I was at university

I vibe coded this with antigravity and cursor but checked every line, also I fixed some details manually

it allows creations of teachers, students, classrooms, subjects, etc. and make connections between them to design schedules

it lacks some features like pagination in some resources and notes grading but I will leave it like this because some things are specific to organizations

you can try it at this url https://academic.jakeactually.com/

it is a standard ruby application so you can host with ```rails server```
